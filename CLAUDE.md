## GUI image requests

Read [the GUI visual guide](docs/gui-visual-guide.md) before implementing or requesting GUI
work. Use its palette and image corrections, with mockup 9 as the main theme reference.

Codex generates GUI mockups from your briefs. Read
[the image handoff](tools/image-handoff/README.md) before requesting an image.
Write briefs in `tools/image-handoff/requests/`. Read the matching replies in
`tools/image-handoff/responses/`. Codex owns the replies and requested image files.
